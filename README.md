# zuraffa_browser_agent

`BrowserAgent` for the Zuraffa ecosystem: browser-specific tools, durable extensions, security policies, and composition over `zuraffa_agent` and `zuraffa_browser_core`.

This package contains no independent agent loop, provider client, transcript store, compaction, durable scheduler, WebView implementation, or product-domain entities.

Architecture: [pi, Zuraffa Agent, and BrowserAgent Architecture Plan](https://github.com/arrrrny/zuraffa_browser/blob/master/handoffs/2026-11-22-pi-zuraffa-browser-agent-architecture-plan.md).
